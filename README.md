# Simple Interest Calculator

A simple web application to calculate simple interest based on principal amount, interest rate, and time period.

## Formula
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal Amount
- **R** = Annual Interest Rate (%)
- **T** = Time Period (in years)

## Features
- Input principal, rate, and time duration
- Instant simple interest calculation
- Easy-to-use user interface
